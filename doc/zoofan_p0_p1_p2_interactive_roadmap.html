真正的产品路线

不是“爬虫 → 网站 → App”，而是每一步验证下一步。
Phase 0

验证内容

确认全球动物园资讯能稳定获取，并找出真正能驱动用户兴趣的题材、动物、事件和叙事方式。

→
Phase 1

占领入口

把已验证的内容模型沉淀为 Zoofan 自己的 Web 产品，让用户主动访问、收藏、搜索和 Follow。

→
Phase 2

建立关系与社区

当用户存在高频 Follow、通知、照片分享与复访需求时，再进入 App 和社区阶段。

P0 核心架构

这四块做完，P0 才算真正形成系统。
01 · SUPPLY

Supply Engine

动物园注册、来源发现、抓取、解析、去重、运行记录与错误监控。

02 · INTELLIGENCE

Content Intelligence

识别 Zoo / Animal / Event，并对重要性、趣味性、稀缺性、小红书适配度评分。

03 · PUBLISH

Publishing Engine

生成中文标题、正文、标签、封面/配图建议，进入人工审核与发布队列。

04 · LEARN

Performance Analytics

记录浏览、点赞、收藏、评论和粉丝增长，反向训练选题与内容策略。

Zoofan 路线的一句话版本

P0 验证内容 → P1 占领入口 → P2 建立关系和社区。 每个阶段都应该用 Gate 决定是否进入下一阶段，而不是因为“计划里写了 P2”就自动去做 App。
